# 常见问题

## 词有戏是什么？

一款 **Windows / macOS 桌面端**语言学习工具：导入本地视频与字幕，按时间轴拆句学习、逐词标记认识与否，为生词安排间隔复习，复习时可一键回放当初学过的原句与画面。

## 支持哪些视频和字幕？

- **视频**：常见本地格式，如 MP4、MKV、MOV 等
- **字幕**：外挂 `.srt`、`.ass`、`.vtt` 等；支持**双语字幕**，也可在主字幕后单独加载**辅助字幕**对照阅读
- **批量导入**：多集视频拖入后，可按文件名中的集数标记自动配对字幕

导入步骤与演示见 [快速上手](/guide/quick-start)。

## 需要联网吗？

**不必联网**也能完成核心流程：导入媒体、播放、按句跳转、认词标记、间隔复习与本地词库管理。

以下情况会用到网络：

- **播放中查词**：需连接在线词典服务获取释义
- **检查更新、账号登录、专业版云同步**等：由你主动触发或开启，非日常学习必需

## 学习数据存在哪里？

默认保存在本机**应用用户数据目录**（视频文件本身仍在你原来的文件夹，软件主要记录路径、解析结果与词库）。在 **设置** 中可 **导出 / 导入** gzip 备份：「仅单词」或「全量」（含视频、字幕与相关资源索引）。

换机或重装前请先导出备份；卸载后是否残留文件取决于操作系统。详见 [隐私政策](/legal/privacy-policy) 与 [设置与偏好](/guide/settings)。

## 和 Anki 有什么区别？

词有戏围绕 **影视字幕流程** 设计：时间轴拆句、学习时按句跳转视频、复习时回放原句。Anki 是通用间隔记忆工具，适合自建卡片与跨平台复习。

二者可以互补使用：在剧里认下的词留在词有戏词库中复习；Anki 可继续承载其它教材。**目前不提供**与 Anki 的自动导入 / 导出同步。

## 支持学哪些语言？

在 **设置 → 学习语言** 中选择或添加：

- **内置**：英语、德语、西语、法语、意大利语（自动做词形归并，如 *book* / *books* 视为同一词）
- **自定义**：其它语种可按空格分词收录，适合暂无专用分词支持的语言

不同语言下的词库与视频列表**彼此独立**。字幕用什么语言，就导入对应语言的字幕并切换到匹配的学习语言。

## 有手机版或网页版吗？

目前没有。词有戏专注 **Windows / macOS 桌面端**，以便本地解码大体积视频、精确对齐字幕时间轴，并在复习时稳定回播片段。

## 字幕版权有问题吗？

词有戏 **不提供** 任何影视资源或字幕下载。请仅使用你合法获得的视频与字幕；应用只在你的电脑上处理本地文件，不对内容版权负责。

## 下载链接在哪里？

请前往 [下载页](/download) 获取当前 **Windows / macOS** 安装包与版本说明。请勿从不明来源下载。
